# PulseForge design system

The reference screen is stored at `Design/pulseforge-concept.png`.

## Tokens

| Role | Value |
| --- | --- |
| App background | `#11151D` |
| Primary panel | `#1A202B` |
| Raised panel | `#222A37` |
| Border/grid | `#323C4B` |
| Primary text | `#E9EDF5` |
| Muted text | `#8F99AA` |
| Primary accent | `#9B6CFF` |
| Secondary accent | `#34D7D5` |
| Record/accent red | `#FF6475` |
| Note/lead amber | `#FFC94A` |

Typography uses Segoe UI for Windows chrome and Consolas for time and meter readouts. Panels use compact 38-pixel headers, subtle 1-pixel borders, and 3-pixel radii. Controls remain rectangular and information-dense so the interface reads as a production tool rather than a dashboard.

## Primary components

- application menu and transport command bar
- instrument browser rail
- 8-track step sequencer
- interactive 16-step piano-roll grid
- 8-channel mixer rail
- status bar with audio-engine information

The implementation deliberately keeps an original product identity and does not reproduce FL Studio branding, proprietary assets, or its exact layout.
